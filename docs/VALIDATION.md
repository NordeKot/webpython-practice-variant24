## Повторение

Полный прогон: test.bat или команды из README.md.
Только MBT:

```sh
python -m coverage run -m pytest -q tests/test_mbt.py
python -m coverage report -m
python -m coverage html
```

После отдельного прогона запустите test.bat снова, чтобы получить
общий отчёт. HTML-отчёт создаётся в htmlcov; не добавляйте
сгенерированные отчёты в git-репозиторий.

## Исправление теста закрытого сокета — 13.10.2026

На Windows дополнительный recv после полного закрытия клиента мог
вызывать WinError 10053. Этот recv не проверял работу обработчика и
создавал лишнее предположение о поведении ОС. Тест исправлен:
при полном закрытии он проверяет, что Handler завершается без исключения;
при завершении только записи клиента проверяет JSON-ответ об ошибке.
Оба сценария генерируются Hypothesis, тест не пропущен и не отключён.

После исправления в Linux: **12 passed in 6.97s**; pycodestyle, проверка
документации W505 и Ruff проходят. Покрытие осталось 99.42%.
Повторный запуск на Windows ещё требуется.
После успешных тестов test.bat открывает htmlcov/index.html в браузере.
При ошибке тестов скрипт по-прежнему останавливается и сообщает об ошибке.
